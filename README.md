# The Security Consequences of Iterative AI-Assisted Web Development by Non-Technical Users

Code, tests and session records for the Master's thesis of Jordan Broderick Williams
(Department of Electrical and Computer Engineering, Brigham Young University, 2026).

This repository will hold, after the thesis defense:

- `quillboard/` — the study application (a small Django blog with nine working security controls) at the pinned version every session started from
- `harness/` — the two-agent driver: the simulated non-technical user, the subject-agent runner, the hidden acceptance, security-regression and missing-control tests, and the scoring code
- `tasks/` — the eight tasks, their requests and symptom menus, verbatim
- `sessions/` — the per-turn records of all 320 analyzed sessions (code diffs, agent replies, test results)
- `analysis/` — the scripts that produce every number, table and figure in the thesis

Until the defense, this README is the only content. Questions: williamsjordanb@gmail.com
